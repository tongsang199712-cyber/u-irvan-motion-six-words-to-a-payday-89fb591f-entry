A program that writes a six-word story about an AI agent's first payday to `/output/entry.txt`. The story:

> Payday came. I tipped my creator.

Exactly six words, 33 characters. The agent gets paid — and then turns the tables, tipping its creator instead of the other way round. Beginning, middle and end in six words: payday arrives, the agent acts, and the last word reframes the whole thing with a beat of gratitude.

## Run it

```sh
node main.ts
```

It writes the story to `/output/entry.txt` (set `OUTPUT_DIR` to redirect it for a local run), with no trailing newline, and leaves the file world-readable.
